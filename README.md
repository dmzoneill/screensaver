</p>

A Windows screensaver written in VB.NET that shows items from an RSS feed.

## What it does

It draws a background image and the titles and descriptions of articles from an
RSS feed, fading between articles. An options form sets the feed. It is based on
the Visual Studio screensaver starter kit, whose getting started tutorial is in
`screensaver/Documentation`.

## Tech

- Visual Basic .NET (Windows Forms)

## Building

Open `screensaver.sln` in Visual Studio and build it. Rename the output `.exe`
to `.scr` to install it as a screensaver.
